# ✨ NoteSpace – Your Personal Thinking Space

A modern and responsive **React Notes Management Application** designed to help users capture ideas, organize thoughts, and manage notes in one beautiful workspace.

## 🌟 About the Project

NoteSpace is a user-friendly notes application built using React.js. It provides a simple and elegant interface where users can create, edit, delete, search, categorize, and pin their notes.

The application uses browser Local Storage to preserve notes even after refreshing the page.

## 🚀 Features

- 📝 **Create Notes** – Create notes with titles and descriptions.
- ✏️ **Edit Notes** – Update existing notes whenever needed.
- 🗑️ **Delete Notes** – Remove unwanted notes.
- 🔍 **Search Notes** – Quickly find notes using keywords.
- 📂 **Category Management** – Organize notes into Personal, Work, Study, and Ideas.
- 📌 **Pin Notes** – Keep important notes at the top.
- 🎨 **Colorful Notes** – Choose different colors for your notes.
- 💾 **Local Storage** – Automatically save notes in the browser.
- 📊 **Dashboard** – View total notes, pinned notes, and categories.
- 📱 **Responsive Design** – Works across desktop and mobile screens.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ancybijuu/NoteSpace.git
```

### 2. Navigate to the project directory

```bash
cd NoteSpace
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:5173
```

## 📖 How to Use

1. Open the NoteSpace application.
2. Click **Create a note**.
3. Enter your note title and content.
4. Select a category and note color.
5. Save your note.
6. Use the search bar to find notes.
7. Pin, edit, or delete notes whenever required.
